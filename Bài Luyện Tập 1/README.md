## 📌 Tóm tắt nội dung

### Phần A: Câu hỏi ôn tập lý thuyết
1. **Câu 1:** Khái niệm phát triển ứng dụng mobile đa nền tảng; Phân tích lợi thế rút ngắn thời gian và giảm thiểu chi phí khi dùng một cơ sở mã nguồn duy nhất.
2. **Câu 2:** Sự cần thiết của phát triển ứng dụng đa nền tảng trong bối cảnh thị trường di động phân mảnh; Các tiêu chí doanh nghiệp nên ưu tiên chọn đa nền tảng.
3. **Câu 3:** React Native là gì? Cơ chế hoạt động chi tiết: vai trò của JavaScript Engine (Hermes/JSC), Bridge (Cầu nối bất đồng bộ JSON) và Native Views (Ánh xạ widget gốc).
4. **Câu 4:** Bảng so sánh toàn diện giữa ứng dụng Native và ứng dụng React Native theo 7 tiêu chí trọng điểm.
5. **Câu 5:** Tầm quan trọng của các kiến thức React nền tảng (JSX, Component, Props, State) và liên hệ thực tế trong xây dựng ứng dụng di động.

### Phần B: Bài tập luyện tập thực hành
1. **Bài tập 1 (Mức dễ):** Phân tích ứng dụng Thương mại điện tử (Shopee / Tiki) và đánh giá tính phù hợp tuyệt đối khi xây dựng bằng React Native.
2. **Bài tập 2 (Mức dễ - trung bình):** Đoạn văn phân tích so sánh chuyên sâu giữa Native và React Native trong từng bối cảnh chiến lược (Tối ưu hiệu năng, Time-to-Market, Ngân sách, Bảo trì).
3. **Bài tập 3 (Mức trung bình):** Sơ đồ quy trình hoạt động 5 bước của React Native và lý giải vì sao mang lại trải nghiệm tiệm cận Native nhưng vẫn chia sẻ mã nguồn.
4. **Bài tập 4 (Mức trung bình - khó):** Tình huống thực tế cửa hàng thời trang: Đề xuất giải pháp React Native, phân tích ưu điểm, rủi ro và phương án khắc phục rủi ro.
5. **Bài tập 5 (Mức khó):** Kế hoạch chi tiết thiết lập môi trường phát triển (Node.js, JDK 17, Android Studio, SDK, AVD Emulator, VS Code) và hướng dẫn chiến lược chọn Expo CLI vs React Native CLI.
